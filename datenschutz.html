Adressverwaltung: Datenschutzerklärung

Die Adressverwaltung ist eine private Anwendung von Andreas Mutzke für die eigenen Kontakte. Sie wird nicht öffentlich angeboten.

Welche Daten verarbeitet werden

  • Kontakte aus dem eigenen Google-Konto (Google Kontakte), um sie mit der eigenen Adressdatenbank abzugleichen.
  • Dateien im versteckten App-Ordner des eigenen Google Drive, um die Kontakte zwischen eigenen Geräten auszutauschen.

Wo die Daten liegen

Die Daten bleiben im eigenen Google-Konto, auf dem eigenen Rechner und im Browser der eigenen Geräte. Diese Webseite enthält nur das Programm und keine Kontaktdaten. Es gibt keinen Server der Anwendung, keine Weitergabe an Dritte, keine Werbung und keine Auswertung.

Google-Nutzerdaten

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Zugriff widerrufen

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions entfernen. Die im Browser gespeicherten Daten werden mit dem Löschen der Website-Daten entfernt.
